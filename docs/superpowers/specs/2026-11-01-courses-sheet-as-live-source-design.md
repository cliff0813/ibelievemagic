# Google Sheets 課程資料即時同步設計

日期：2026-11-01

狀態：設計已核准，尚未實作

## 目標與範圍

讓 Google Sheets 成為 GitHub Pages 課程列表、課程詳情與 Apps Script 報名頁共用的課程資料來源。課程內容在試算表儲存後，訪客重新載入網站即可看到最新資料，不需要重新建置或部署 GitHub Pages。

網站公開顯示的資料包含標題、日期、時間、地點、上課方式、圖片、課程說明、課綱、講師資料及費用級距。報名者個資、報名紀錄與管理資料不得由公開課程端點傳回。既有報名流程須維持可用。

不包含線上試算表管理介面、金流、報名名額計算或 SEO 預先渲染即時 Sheet 資料。GitHub Pages 為靜態主機；為避免每次編輯 Sheet 都觸發部署，本設計接受課程內容由瀏覽器端載入，SEO 與未執行 JavaScript 的爬蟲可見度會低於預先渲染。

## 架構與資料流

- **資料來源：** Apps Script 綁定的 Google 試算表。Courses 保留現有課程識別、標題、日期、時間、地點、上課方式、圖片及報名模式欄位，並增加課程說明、講師名稱與講師介紹。
- **多筆課程內容：** 新增 `CourseOutline` 分頁，欄位為 `courseId`、`sortOrder`、`item`；新增 `CoursePricing` 分頁，欄位為 `courseId`、`sortOrder`、`label`、`price`。以 `courseId` 關聯，依排序欄位輸出。
- **安全遷移：** 初始化只新增缺少的標題與分頁，不清除或覆寫現有資料。為既有課程補入網站目前已有的描述、講師、課綱與費用時，只填補空白欄位／缺少的關聯資料；不得覆寫試算表已填值。
- **公開唯讀端點：** Apps Script 公開部署提供獨立的 JSONP 課程資料回應。只輸出網站允許公開的欄位；回呼名稱需嚴格驗證，且不得包含報名者資料、管理資料、試算表 ID 或部署私密資訊。課程展示端點與報名可報名清單分開，避免展示需求意外改變報名截止行為。
- **網站：** Next.js 靜態輸出保留外殼與頁面路由；瀏覽器端在課程列表與詳情載入時請求公開端點。現有 `/courses/<id>/` 詳情網址維持可用；列表改連至可透過 query ID 讀取課程的通用靜態詳情頁，讓新增的 Sheet 課程不需重新產生靜態路由。
- **更新時機：** 每次頁面載入讀取目前 Sheet 內容；編輯試算表後重新載入即可更新。若需程式碼變更，仍依既有程序推送 Apps Script 並發布新 Web App 版本；但日常課程資料編輯不需部署程式碼或 GitHub Pages。

## 顯示與錯誤處理

- 課程列表顯示日期、時間、標題、講師、說明摘要及起始費用；詳情頁顯示完整說明、依序排列的課綱、講師介紹、地點、上課方式及費用級距。
- API 成功但找不到指定 `courseId` 時，詳情頁顯示明確的課程不存在狀態。
- API 讀取失敗或回應格式無效時，顯示明確錯誤與重試操作；不可用舊版 JSON 假裝為最新資料。
- 公開端點只傳回經過白名單整理的課程欄位。JSONP callback 僅接受安全識別字格式；輸出資料使用 JSON 序列化，不將使用者資料串接成可執行程式碼。
- 日期以固定的 `Asia/Taipei` 語意解析，不依建置伺服器的本機時區換算，避免日期少一天。

## 相容性與部署

- 保留現有 Apps Script 公開報名與管理部署的分工及存取控制。
- `listOpenCourses()` 仍依原本報名可用性規則工作；新的網站課程展示端點不使用其開放狀態篩選。
- Sheets 結構更新採可重複執行且不破壞既有資料的遷移；不得因增加欄位而靜默忽略或重設目前的 Courses 資料。
- Apps Script 公開部署程式更新需要推送並發布新版本一次。其後只修改課程列與內容分頁即可更新網站。
- 文件須說明欄位、排序方式、初始化／遷移程序、公開資料範圍及程式更新後的 GAS 部署程序。

## 測試與驗收

- GAS 測試：既有 Courses 表遷移會保留資料；重複執行不重複新增；空白欄位可從備援資料補入而非覆寫既有值；課綱與費用依 `sortOrder` 關聯及排序。
- GAS 端點測試：只回傳公開欄位；callback 驗證拒絕不合法輸入；JSONP 對特殊文字安全序列化；課程展示不受報名截止狀態影響；試算表讀取錯誤明確失敗。
- 網站測試：課程列表及詳情採端點資料；新 `courseId` 可由通用詳情頁載入；未知 ID、端點失敗與無效回應呈現明確狀態；課綱／費用順序正確。
- 日期測試：同一日期字串在 UTC 與台北時區皆顯示相同日曆日期。
- 回歸驗收：既有 GAS 報名、課程預選、手動報名模式與 GitHub Pages 靜態建置保持有效；部署後修改 Sheet 的地點、說明、課綱及費用，重新載入網站可看到對應變更，無需重新部署網站。
